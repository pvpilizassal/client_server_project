# Client–Server Time Exchange (C++ 17 Qt6) 

Два минималистичных приложения на C++/Qt (Widgets), обменивающиеся
данными о времени по протоколу UDP. Настройки хранятся в JSON-профилях
пользователя. Целевые платформы — Linux и Windows

## Состав проекта
- **server/** - Приложение «Сервер»: задаёт время и рассылает его клиенту
- **client/** - Приложение «Клиент»: отображает время на аналоговом циферблате 
- **common/** - Общий модуль: протокол, базовый класс конфигурации 

«Сервер» и «Клиент» - GUI-приложения на Qt Widgets. Сетевое взаимодействие
инкапсулировано в классах ServerCore и ClientCore, не зависящих от GUI;
графический интерфейс реализован в ServerWindow и ClientWindow

## Зависимости для сборки
- CMake >= 3.16
- Компилятор с поддержкой C++17
  - Linux: GCC >= 9 или Clang >= 10
  - Windows: MSVC 2019/2022 или MinGW 11+
- Qt 6 (компоненты Core, Gui, Widgets, Network)

## Запуск
Запустите server и client. По умолчанию оба используют порт 12345
и адрес 127.0.0.1, поэтому на одной машине они найдут друг друга сразу
Для работы по сети укажите в JSON-профиле «Клиент» IP-адрес машины с сервером

## Протокол обмена
Обмен идёт по UDP. Оба приложения используют один и тот же порт
(по умолчанию 12345); клиент отправляет пакеты на адрес сервера,
сервер отвечает на адрес и порт, с которых пришёл последний пакет

**Клиент -> Сервер: пакет присутствия**
Отправляется 1 раз в секунду. Служит двум целям:
- Сообщить серверу, что клиент жив.
- Сообщить серверу свой обратный адрес и порт (порт, выделенный ОС), чтобы сервер знал, 
куда отправлять время

**Сервер -> Клиент: пакет времени**
Значение - количество секунд от полуночи, диапазон 0 ... 86399
(00:00:00 ... 23:59:59). Big-endian выбран для однозначности на всех
архитектурах (x86, ARM и т. д.)
Отправляется 1 раз в секунду, но только если сервер уже знает адрес
клиента (то есть получил хотя бы один пакет ALIVE)

## Логика работы приложений
### Сервер
- Хранит текущее время (QTime), отображает его в QTimeEdit и рассылает клиенту 1 раз в секунду
- Если пользователь не редактирует поле, время увеличивается на 1 минуту каждую секунду. 
Поле перерисовывается, когда оно не в фокусе, чтобы не мешать вводу. Инкремент выполняется всегда
- При изменении времени пользователем (сигнал QTimeEdit::timeChanged)
новое значение становится текущим и продолжает инкрементироваться с той же частотой
- Статус «Клиент видит время» обновляется каждую секунду по таймауту
последнего полученного пакета ALIVE
### Клиент
- Каждую секунду отправляет ALIVE серверу
- При получении пакета времени обновляет аналоговый циферблат
(часовая и минутная стрелки; секундной нет — сервер передаёт время
с точностью до минуты)
- Статус «Данные о времени актуальны» обновляется каждую секунду
по таймауту последнего полученного пакета времени

## Хранение настроек
Настройки хранятся в JSON-файлах профиля пользователя. Путь
вычисляется через QStandardPaths::AppConfigLocation и зависит
от ОС и от QCoreApplication::setOrganizationName /
setApplicationName (заданы в main.cpp обоих приложений)
- **Linux** ~/.config/TestTask/TimeServer/ и ~/.config/TestTask/TimeClient/
- **Windows** users\username\AppData\Local\TestTask\TimeServer\ и …\TimeClient\
Содержимое файла настроек:
server_config.json
{
    "port": 12345,
    "time": 0
}
client_config.json
{
    "serverAddress": "127.0.0.1",
    "serverPort": 12345
}
